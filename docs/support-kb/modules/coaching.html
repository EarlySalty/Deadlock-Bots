Coaching

Coaching wird über die Community-Website angestoßen: Termine werden mit dem Server abgeglichen, du bekommst persönliche Erinnerungen per DM und nach dem Termin kurzzeitig Zugriff auf einen Feedback-Kanal. Wer einen Termin nicht wahrnimmt, kann eine befristete Buchungssperre erhalten.

Was Mitglieder merken

Als Mitglied merkst du vom Coaching vor allem drei Dinge. Wenn auf der Coaching-Website ein Termin für dich ansteht, wird er mit dem Server abgeglichen und du erhältst eine persönliche DM mit Hinweis und einem Link zur Website. Nach einem wahrgenommenen Coaching hast du für eine begrenzte Zeit Zugriff auf einen Feedback-Kanal. Nimmst du einen gebuchten Termin nicht wahr, kann bei einer neuen Buchung eine befristete Sperre angezeigt werden, jeweils mit Ablaufzeit und Grund. Die eigentliche Buchung und die Terminverwaltung passieren auf der Website, nicht im Discord.

Mögliche Ausgänge

  • Erinnerungs-DM zugestellt
  • Zeitlich begrenzter Zugriff auf den Feedback-Kanal nach dem Termin
  • Aktive Buchungssperre nach Nichterscheinen (mit Ablaufzeit und Grund)
  • Keine aktive Sperre, Buchung möglich

So läuft es ab

  1. Ein Coaching-Termin entsteht bzw. wird auf der Community-Website angelegt
  2. Der Termin wird mit dem Server abgeglichen
  3. Das Mitglied erhält eine persönliche Erinnerungs-DM mit Website-Link
  4. Nach dem wahrgenommenen Termin gibt es für begrenzte Zeit Zugriff auf einen Feedback-Kanal
  5. Wird ein Termin nicht wahrgenommen, kann bei einer neuen Buchung eine befristete Sperre mit Ablaufzeit und Grund angezeigt werden

Typische Meldungen & Fehler

SignalWas es bedeutetNächster Schritt
Keine Coaching-Erinnerung angekommenDer Abgleich der Termine mit dem Server hat nicht gegriffen, deshalb kam keine Erinnerung anBeim Team/Support melden, damit der Abgleich geprüft wird

Das darf der Support sagen

  • Coaching-Termine laufen über die Website; steht dort ein Termin, bekommst du eine persönliche Erinnerung per DM mit Link.
  • Kommt keine Erinnerung an, kann der Abgleich gehakt haben. Melde dich beim Team, wir prüfen das.
  • Nach einem wahrgenommenen Coaching hast du für begrenzte Zeit Zugriff auf den Feedback-Kanal.
  • Eine Buchungssperre nach einem verpassten Termin ist befristet und endet automatisch. Ablaufzeit und Grund werden dir angezeigt.

Nie an Mitglieder weitergeben

  • Interne Zahlen jeder Art: Schwellen, Sicherheitswerte, Gewichte, Zeitgrenzen, Limits.
  • Die interne Entscheidungs- oder Durchsetzungslogik — welche Signale zu welcher Wirkung führen und in welcher Reihenfolge.
  • Interne Technik: IDs, Pfade, Endpunkte, Namespaces, KI-Anbieter oder -Modelle, Zugangsdaten.
  • Verdeckte Mechaniken oder Betriebsarten — auch nicht andeutungsweise, welche es geben könnte.
  • Im Zweifel abstrahieren und an einen Menschen eskalieren (Details im Agenten-Leitfaden).
